# v1.4.0 受控随机升级收尾

日期：2026-10-31

## 1. 试玩反馈

原升级系统会先过滤不可用项，再用 `UnityEngine.Random.Range` 无放回抽取，因此同一组三选一不会重复，但相邻升级可能连续出现相似组合，关键成长方向也可能较久不出现。

## 2. 实现

- 新增 `UpgradeChoiceSelector`，把候选选择从 UI 控制器中拆出；
- 保留每三级武器升级和 `CanApply` 上限过滤；
- 上一轮出现的资源权重乘 `0.32`；
- 未出现轮数每轮增加权重，最多补偿六轮；
- 生命不高于 `35%` 时提高治疗和最大生命权重；
- 使用带权无放回抽取，保证同组三项资源不重复；
- 开始新一局选择初始武器时重置历史，避免上一局影响下一局。

## 4. 面试说明

升级随机不是简单调用一次随机数。系统先做合法性过滤，再通过独立选择器进行带权无放回抽取。近期重复抑制减少相邻升级雷同，长期未出现补偿防止关键成长方向永久缺席，低血量权重让随机结果对当前战斗状态有有限响应，但不会绕过数值上限或武器等级规则。
